# Commentary Archive

A private-first place to keep comments, quotes, links, screenshots, and the thoughts they sparked.

Everything is stored in the browser with IndexedDB. There are no accounts, trackers, ads, or shared feeds. Backups can be exported and restored as JSON.

## What it does

- Saves quotes and comments with their original source links
- Preserves YouTube comment deep links
- Keeps remarks in a simple Inbox or Saved view, with tags and search
- Resurfaces five deterministic highlights each week, rotating every Monday
- Turns screenshots into editable text with a bundled, on-device OCR engine
- Works offline after the first visit
- Exports and restores the full archive

## Run locally

Serve the `dist` folder with any static web server, then open it in a modern browser.

## Privacy

Your archive never leaves your browser. Clearing site data removes it, so download backups regularly.
